本文件是入口，不保存操作明細。所有數值均為歷史觀測，操作前須重新核驗。

## 寫入與查閱

- 新紀錄寫入 `docs/logs/YYYY-MM.md`，同月依日期及時間倒序排列。原有分卷保留遷移前順序，不以檔案位置判斷新舊。

- 每筆使用 `## YYYY-MM-DD HH:mm +0800：主題`，保留來源訊息 ID；新增唯一且不再變更的 HTML anchor。

- 引用使用分卷路徑加 anchor，連結文字包含日期與時間，不只寫「詳 NOTES09:10」。更新每日索引時只需保留該日入口。

- 未明示日期的舊章節放在 `legacy.md`，不從鄰近段落猜測日期。
