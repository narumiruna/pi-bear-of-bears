# 上下文精簡原文查閱回饋

記錄 Agent 使用 `bears_original` 的實際情境，作為改善 `extensions/compact-context.ts`、原文查閱及輸出預覽的依據。紀錄規則見 [`AGENTS.md`](../AGENTS.md#原文查閱回饋)。

同一情境、同一來源的連續分頁合併一筆；不同來源分別記錄並可互相引用。查閱失敗或未能解惑仍須記錄。只保留最小必要摘要，不貼完整聊天或私人檔案路徑。

## 紀錄範本

<!-- 複製此範本新增實際紀錄，不將範本當作已發生的事件。 -->

```markdown
### YYYY-MM-DD HH:mm（時區）— 問題簡述

- 任務與待做判斷：
- 來源：工具名稱或 bears-watch；originalSourceId（不明時註明）
- 不清楚之處：當時看到了什麼？哪些資訊缺漏、矛盾或需要精確原文？
- 查閱範圍：各次 offset／limit，以及是否仍有下一頁
- 原文發現：最小必要摘要；失敗時記錄錯誤類型
- 結果與後續：已解決／未解決；對判斷的影響、是否需要新觀測
- 原因分類：精簡資訊遺失／輸出截斷／原始訊息不清／觀測過期／其他／待確認
- 改善建議：具體可調整的呈現、保留欄位、提示或測試案例；無建議可註明
```
