# 遊戲指令與工具回饋

記錄 game commands／tools 的使用問題、疑似 bug 與改善構想。規則見 [AGENTS.md](../AGENTS.md#遊戲指令與工具回饋)；本文件不授權操作，也不把歷史觀測當成即時狀態。

## 記錄格式

每個問題使用唯一 ID 與標題；相同問題更新同一條目。

- 日期／時區、分類（使用問題／疑似 bug／改善構想）、狀態（待查證／已確認／已修復／不採用）。
- 情境、指令或 tool、必要參數及適用版本（未知則明示）。
- 預期結果、實際結果與證據定位（訊息 ID、`originalSourceId` 或測試路徑）。
- 影響、安全替代方式、下一步；已修復時附驗證結果與適用範圍。

只保留必要摘要，不貼憑證、個資或完整聊天。原文缺漏另記[原文查閱回饋](compact-context-feedback.md)，遊戲收支另記[遊玩紀錄](NOTES.md)，此處連結證據即可。
