# なるみ持續打王／無盡星塔並提升戰力

## 主要目標

- 對象僅為既有角色 `なるみ`，以遊戲即時角色回覆核對；不包含其餘八個角色。
- 讓 `なるみ` 一直打王或無盡星塔，持續選擇可安全推進的戰鬥。
- 想辦法提升 `なるみ` 自身戰力，研究並執行對本人有利的裝備提升。
- 新增可驗收里程碑：通過無盡星塔第100層，並擊敗第1–100層全部 BOSS；BOSS 樓層、名單及勝利紀錄以遊戲回覆核對，不預設數量，也不把進入100層當成通關。
- 新增可驗收里程碑：`なるみ` 的 gallery 316張全部取得、79種怪全部解鎖。316張及79種是使用者指定的目標，不是目前已達成數；以本人 `/gallery` 的即時總覽與各怪收藏明細驗收。
- 持續任務本身仍沒有停止門檻，不設定戰力數值或累計操作次數作為終點；一次擊殺、通關、換裝或強化，以及新增里程碑達成，均不代表可以自行結束整個持續任務。
- 以遊戲戰報、實際 HP／MP、技能與屬性變化、塔進度、掉落、收藏解鎖及資源淨變化評估成果，不以單一裝備評分替代實戰戰力或收藏完成度。

## 研究工作

1. 核對本人角色、位置、HP／MP、技能、完整背包及已穿裝備，選擇可驗證的安全戰鬥或裝備提升途徑。
2. 比較既有裝備的免費換裝與王裝進化，先確認裝備資格、技能／被動取捨、本人收益及即時費用，避免只因能進化就投入較弱候選。
3. 逐場打王或推進星塔至100層，依實際承傷、輸出、恢復與資源餘量調整下一步；核對第1–100層全部 BOSS 的勝利證據及缺口，確認塔內查詢與戰鬥機制，不把野外評估結果直接套到星塔。
4. 取得本人 `/gallery` 總覽與收藏明細，分別盤點316張圖片及79種怪的已解鎖／未解鎖項目。查證各缺項的實際取得條件，選擇已授權且安全的取得途徑；怪物擊敗、塔首達或掉落不是圖片已收藏的替代證據，不以死亡取得收藏。
5. 在通層、BOSS 勝利、收藏解鎖、換裝、進化或恢復後，保存已確認成果、穿戴、實際支出、星塔／gallery 缺口及下一步於 `docs/NOTES.md`，必要時更新 `docs/CHARS.md`。記錄是執行中的檢查點，不是每批工作的終點；寫完後接著執行安全且已授權的下一步。

## 未達標時的續行與停損

- 在目前工作階段中，只要仍有安全且已授權的下一步，就接著執行；不因通過一層、完成一筆進化、累積一批戰果、更新文件或準備進度摘要而自行結束本次工作。一般10次操作與單次配裝額度不適用本任務。
- 每場戰鬥或裝備提升後核對結果並選擇下一步：血魔不足先恢復，恢復成功後接回原挑戰；通層後評估新敵人；取得裝備後比較本人收益，再決定換裝、進化或續戰。滿血魔、安全前庭或保留中的塔挑戰是續行條件，不是停止門檻。
- 沒有可打的王時評估星塔；星塔無法安全推進時，評估已有裝備、王裝進化、其他可達 BOSS 及 gallery 缺項的安全取得途徑，不為維持活動重複已排除的低效操作。若收藏缺項只能靠死亡、未授權操作或外部修復取得，記錄具體條件並保持該里程碑未完成，不為湊齊316張犧牲保命界線。
- 遇到結果不明、rate limit 或其他必須停止該批的情況，依 `AGENTS.md` 停止相關操作，不以持續目標為由重送。若只能依賴王重生、外部資源恢復、連線修復或新增授權，記錄具體阻礙、最後確認狀態及下一次可驗證行動，結束本次工作而非宣稱目標完成；可立即執行的安全恢復不屬於外部等待。
- 若工作階段因中斷或 context 交接而必須結束，保存角色、位置、血魔、挑戰與敵人剩餘HP、裝備、資源、最後訊息ID、已送但未確認的操作及下一個可驗證行動。收到有效續行要求後先重新觀測，再從檢查點接續，不把「下一步待續」當成停止理由，也不自行啟動背景操作。
- 真正需要收尾時，優先脫離危險並在可確認的安全位置恢復；不擅自改成原生掛機或操作其他角色。

## 授權與安全界線

- 以 `なるみ` 不死亡為優先前提；持續戰鬥與提升戰力不得凌駕保命需求，不為推層、掉寶或測試技能冒已知致死風險。

- 「沒有停止條件」不表示必須硬打；遇到無法確認可存活的敵人時改走其他安全戰鬥或裝備提升途徑，沒有安全下一步則保存檢查點。遊戲隨機機制無法保證零死亡，不以歷史勝利或推估勝算宣稱必定存活。
- 使用者已全面開放本任務需要的手動戰鬥、移動／安全收尾、既有裝備換裝、王裝進化、恢復消耗品與星塔入場材料；資源範圍及未授權操作以 `AGENTS.md`「なるみ持續打王與提升裝備的專屬授權」為準。
