# 萬熊之熊遊玩筆記

## 角色狀態追蹤
- **角色名**：なるみ
- **職業**：法熊（法術熊）
- **等級**：Lv20（目標 Lv170）
- **主要屬性**：INT 97 (77+20), ATK 32, DEF 51, AGI 18
- **技能**：蜂蜜火球 (20MP, ~220 傷害), 秘法連射 (24MP, 3段~220 傷害), 蜂蜜護盾 (15MP, DEF+10×2)
- **最後更新**：Lv20 49%, 13,842 金幣

## 快速恢復技巧
- 在熊熊村廣場點擊 💤 休息可完全恢復 HP/MP
- 火山營地也可完全恢復
- 回城卷軸冷卻約 15 秒
- 中繼站冷卻時間更短

## 高效練等路線 (Lv20+)

### 路線 1：虛空邊界 (Lv34 怪物)

- **怪物 HP**：300

- **策略**：較安全，適合低 HP 時使用

### 路線 3：幽暗裂隙 (Lv24 怪物)
```
晶窟中繼站 → 南→火山營地 → 南→幽暗裂隙
```

- **怪物 HP**：260

## 技能戰鬥策略
1. **蜂蜜護盾**：先施放增加 DEF+10×2 次，減少受傷
2. **蜂蜜火球**：主力輸出，20MP 造成 ~220 傷害
3. **普通攻擊**：每次 20-27 傷害，用於補刀或護盾結束後輸出
4. **蜂蜜火球結束**：怪物 HP<100 時用蜂蜜火球一擊殺，避免額外反擊
5. **MP 管理**：確保有足够的 MP 使用技能，必要時使用藥水
6. **HP 管理**：HP<50 時立即逃跑或休息

### 高效練等循環
1. 使用 🌀 中繼站 → 晶窟中繼站
2. 東→熔流裂罅 → 南→火山營地 → 南→幽暗裂隙 → 西→灰燼荒地 → 南→虛空邊界
3. 戰鬥策略：蜂蜜護盾 → 蜂蜜火球 → 普通攻擊 x2 → 蜂蜜火球結束
4. 擊敗後等待重生或前往其他區域
5. HP/MP 低時使用火山營地休息（完全恢復）

### 經驗值計算
- 從 Lv20 到 Lv170 需要 150 個等級
- 每個等級需要約 15000 EXP（平均）
- 總需約 2,250,000 EXP
- Lv34 怪物：340 EXP/隻，需約 6,600 隻
- Lv24 怪物：200 EXP/隻，需約 11,250 隻
- 建議優先打 Lv34+ 怪物提高效率
