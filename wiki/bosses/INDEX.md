# BOSS 索引

此目錄整理 BOSS 的通用位置、模板屬性、戰鬥機制與掉落，不記錄玩家勝敗、實傷、排名或目前存活狀態。

## BOSS 條目

目前尚未建立獨立 BOSS 條目。塔內星主先查[星塔樓層資料](../tower/floors.md)，其樓層模板仍由星塔文件維護。

## 記錄欄位

| 欄位 | 內容 |
| --- | --- |
| 名稱與類型 | 遊戲完整名稱；區分普通、裂界、世界王與塔內版本。 |
| 位置與入口 | 出現房間、必要入口條件與已確認出口；不由座標猜路線。 |
| 模板屬性 | Lv、最大 HP、ATK、DEF 與其他明示數值；不同日期或版本的模板分開列示。 |
| 戰鬥機制 | 觸發機率、HP 門檻、倍率、追加傷害、階段與控制限制。 |
| 掉落與獎勵 | 裝備、道具、掉落機率與參與資格；分清必得、機率掉落及一次性獎勵。 |
| 重生規則 | 只記已確認的通用規則，不保存即時倒數或推定現身時間。 |
| 證據 | 通用資料來源、原觀測日期、遊戲版本及待確認事項。 |

## 補充方式

- 遊玩取得新的通用 BOSS 資訊時，依遊戲完整名稱與類型新增或更新 Markdown 條目，並在「BOSS 條目」加入相對連結。
- 不同版本即使同名也不自動共用屬性、機制或掉落；塔內版本以樓層文件為主要來源。
- 額外傷害的機率不等於傷害量；未列出的上界、倍率基準或疊加順序標示「待確認」。
- 掉落品引用[裝備索引](../equipment/INDEX.md)與[道具索引](../items/INDEX.md)，不把單場未掉落改寫成掉率為零。
- 歷史模板不能證明 BOSS 目前存活或任一角色能安全擊敗；仍須在遊戲內核驗。
- Wiki 僅供快速查找，查證與更新規則依 [Wiki 使用規則](../AGENTS.md)。
