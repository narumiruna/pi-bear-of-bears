# 裝備索引

此目錄整理裝備的通用屬性、裝備條件、被動、授予技能與取得／強化方式，不記錄玩家持有、穿戴或個人配裝。

## 裝備條目

目前尚未建立裝備條目。已整理的[裝備授予技能](../skills/裝備技能.md)與[星塔首達裝備](../tower/mechanics.md)可作查閱入口，但不是完整裝備圖鑑。

## 記錄欄位

| 欄位 | 內容 |
| --- | --- |
| 名稱與版本 | 遊戲完整名稱、稀有度、進化階段與精煉等級；不同版本分開列示。 |
| 部位與資格 | 裝備部位、需求等級、職業與其他限制。 |
| 屬性 | 遊戲明示的 ATK、DEF、INT、AGI 或其他屬性；區分基值與強化後數值。 |
| 特殊效果 | 被動、套裝、授予技能及觸發條件；技能詳情引用技能文件。 |
| 來源 | 掉落 BOSS、獎勵或合成配方；機率須有明確來源，未掉落不代表不會掉落。 |
| 強化 | 進化、精煉與合成的投入、資格、稅費與副作用；有條件的價格不得寫成固定通價。 |
| 證據 | 通用資料來源、原觀測日期、遊戲版本及待確認事項。 |

## 補充方式

- 遊玩取得新的通用裝備資訊時，依完整名稱新增或更新 Markdown 條目，並在「裝備條目」加入相對連結。
- 同一裝備的各階段集中於同一頁；名稱相近但不同的裝備不得合併。
- 授技效果與數值分開確認，不能由名稱推定；未列出的屬性不直接補零。
- 掉落來源引用 [BOSS 索引](../bosses/INDEX.md)，材料用途引用[道具索引](../items/INDEX.md)，避免重複維護。
- Wiki 僅供快速查找，查證與更新規則依 [Wiki 使用規則](../AGENTS.md)；沒有來源的欄位標示「待確認」。
