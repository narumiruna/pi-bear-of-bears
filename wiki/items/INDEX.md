# 道具索引

此目錄整理非裝備道具，例如恢復品、材料、碎片、票券與任務物品，不記錄玩家持有量、消耗紀錄或任務進度。可穿戴的物品記錄於[裝備索引](../equipment/INDEX.md)。

## 道具條目

目前尚未建立道具條目。

## 記錄欄位

| 欄位 | 內容 |
| --- | --- |
| 名稱與分類 | 遊戲完整名稱、稀有度及用途分類。 |
| 效果與用途 | 恢復效果、配方用途、兌換對象或任務用途。 |
| 使用條件 | 等級、職業、地點、戰鬥狀態、冷卻與次數限制。 |
| 消耗與副作用 | 每次消耗數量、額外費用、不可逆效果，以及已確認的批量使用規則。 |
| 取得方式 | 掉落、獎勵、合成或其他已確認來源；區分取得可能性與保證獎勵。 |
| 證據 | 通用資料來源、原觀測日期、遊戲版本及待確認事項。 |

## 補充方式

- 遊玩取得新的通用道具資訊時，依完整名稱新增或更新 Markdown 條目，並在「道具條目」加入相對連結。
- 名稱相近的通用碎片、裝備專屬碎片與材料須分開記錄；未確認前不視為可互換。
- 材料或任務物品不一定能直接使用，不因描述提到效果就推定可施放、穿戴或兌換。
- 涉及裝備或 BOSS 時，引用[裝備索引](../equipment/INDEX.md)或 [BOSS 索引](../bosses/INDEX.md)，不複製整份條目。
- Wiki 僅供快速查找，查證與更新規則依 [Wiki 使用規則](../AGENTS.md)；沒有來源的欄位標示「待確認」。
