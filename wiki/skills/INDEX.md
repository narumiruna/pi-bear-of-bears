# 職業技能索引

此目錄依職業整理遊戲技能，不是 Agent skills。內容遵循 [Wiki 使用規則](../AGENTS.md)。

## 文件組織

- 每個職業使用一份 Markdown 文件，檔名採遊戲內的完整職業名稱，例如 `戰熊.md`。
- 轉職後的職業分開記錄；共用或繼承的技能以連結引用，不重複維護。
- 新增職業文件時，在下方職業索引加入相對連結。

## 技能記錄內容

- 技能名稱、主動或被動類型、解鎖條件。
- MP、HP 或其他消耗、施放條件與限制。
- 技能效果、持續時間，以及已確認的屬性關係或計算公式。
- 資料來源、觀測日期與驗證限制。

只記錄已取得來源的資料。缺少的欄位標示「待確認」，不得推測數值或將未知消耗寫成零。不收錄玩家個人的技能解鎖狀態、配裝或施放紀錄。

## 查證範圍

<a id="verification"></a>

- 已查詢上述 9 個職業的 `/skills`，共列出 26 個不同的非裝備主動技能；共用技能不重複計數。此清單不代表遊戲全部職業或技能。
- 來源為 [@BearOfBearsBot](https://t.me/BearOfBearsBot) 的通用技能文案，觀測日期為 2026-10-18（UTC）；不保存私人對話、訊息 ID、玩家身分、個人狀態或期望傷害。
- 所有技能效果與倍率皆為選單描述，本次沒有施放技能，不將文案當成已驗證的實戰公式。
- 解鎖等級、前置技能、冷卻、射程、目標數，以及未明示的 HP 或物品成本均待確認；未列出不代表沒有。
- 除已明示各段扣防的共用連擊外，不推定其他多段技能的扣防方式；不推定技能必中、吸血無上限、必定存活或所有場合均可施放。
- 被動技能、未解鎖技能、初始職業的技能繼承關係與完整裝備技能圖鑑尚未查證。
