# 無盡星塔共通機制

本頁是既有遊戲說明與歷史資料的通用摘要，不是本次實機驗證。實際資格、費用與戰鬥機制以當次遊戲回覆為準。

## 入口與指令

| 指令或入口 | 用途 | 限制與副作用 |
| --- | --- | --- |
| 星屑觀測站的「上」出口 | 步行前往星塔前庭 | 依現場出口確認；不以地圖座標推定其他路線。 |
| 「前往星塔前庭」快捷按鈕 | 快速旅行 | 曾要求傳送券，不等同免費步行；使用前核對費用。 |
| `/tower` | 查看最佳樓層、有效挑戰、怪物剩餘 HP，或入場選項 | 有效挑戰與未入場選單內容不同；顯示前庭不代表挑戰已結束。 |
| `/tower go [起始樓層]` | 從前庭開始挑戰 | `[起始樓層]` 替換為當次選單允許的樓層；可能消耗材料或金幣。 |
| `/attack`、`/skill 技能名稱` | 繼續當層戰鬥 | 會觸發戰鬥結算；技能成本另見[技能索引](../skills/INDEX.md)。 |
| `/flee` | 收刀，停止當下戰鬥 | 不等同正式退出；須確認遊戲回覆。 |
| `/rest` | 在前庭恢復 HP／MP | 戰鬥中可能拒絕；先收刀，確認可免費恢復後再使用。 |
| `/tower quit` | 正式結束挑戰，保留個人最佳 | 重新入塔可能再收費，不能當成保留當層怪血的恢復方式。 |

入場與攻擊是不同動作。既有回覆支持入場後先查看當層模板，不必立即攻擊；入場本身仍可能收費。

## 入場費與免費資格

- 選單曾顯示「今日首戰免費」，也曾顯示「星核碎晶 ×2 或 300,000 G，自動擇一」。這些是歷史選單形式，不是永久統一價格或材料優先順序的證明。
- 歷史資料支持免費資格可跨日恢復，且不同角色的當次顯示可能不同；每日必定恢復、確切重置時間、時區與完整資格規則仍待確認。
- 只依本次選單明示的免費資格或完整費用判斷，不沿用前一天資格，也不以其他角色的資格代替。
- 可選起始樓層以當次選單為準，不假定任意跳層或略過未通關樓層。

## 戰鬥與承傷

- 遊戲說明指出塔怪在角色出手時反擊；停手不代表下次出手沒有先機攻擊。
- 官方處理備註曾說明塔怪維持單打、保留先攻，以及塔內單擊封頂；這不等於每次行動最多只受一次傷害。出手前先機與出手後反擊須分開考慮。
- 「單擊最多最大 HP 的 50%」不能推為滿血必活：同次行動可能涉及先機、反擊或特殊追加，且取整、封頂與減傷的順序未完整確認。
- 星主與野外同名 BOSS 不一定使用相同特殊效果。只能使用當層實際列出的機制，不能依怪物名稱移植野外規則。
- 降攻與降防只採已生效的當次回覆，不預借下一招效果，也不將上一層的狀態套到新層。
- 傷害、降攻下限、塔內減傷、特殊追加與封頂的完整公式尚未取得。既有紀錄中的承傷估算及額外餘量不是遊戲公式，不收錄為通用計算規則。
- 不以預估終殺、DOT（持續傷害）、吸血、閃避、暴擊或連擊代替出手前的生存條件。`/consider` 在前庭可能只回覆沒有怪物，不提供可靠的塔內勝率。

## 恢復與保留挑戰

前置條件是仍有有效挑戰、位於星塔前庭，且當次遊戲說明允許收刀與免費恢復。

1. 使用 `/flee`，確認已收刀。
2. 確認前庭恢復條件與零費用，再使用 `/rest`。
3. 確認 HP／MP 實際恢復，以及資源沒有非預期減少。
4. 使用 `/tower`，確認同一挑戰、樓層與怪物剩餘 HP 保留。
5. 重新確認暫時防護與狀態，再決定是否繼續；不假定休息後舊護盾仍有效。

若被拒、怪血改變、挑戰消失或結果不明，停止相依操作並重新查證，不重送入場或恢復指令。

- 既有資料有收刀、前庭休息後怪血保留的案例；不推廣為野外 BOSS 也保血。
- `/recall2` 曾明確結束有效爬塔挑戰；不能拿召回代替前庭恢復。其他離塔方式的影響須分別確認。
- 曾有切角後挑戰保留的案例，但不足以保證所有角色、情境或後續版本皆相同。
- 怪血保留不代表 DOT、易傷或護盾永遠保留；長停後狀態曾不再顯示，確切失效條件待確認。

## 獎勵

| 類型 | 已有說明或歷史摘要 | 不得推定的內容 |
| --- | --- | --- |
| 怪物獎勵 | 擊敗怪物可列出金幣與 EXP | 不以滿級時的 EXP 宣告當成實際升級收益。 |
| 首達獎勵 | 首次通層另列獎勵 | 重打已通樓層不能預期再領首達獎；金幣曾有日期差異，不套用舊倍率。 |
| 星墜遺寶 | 選單列 15／25／35／45／55／65 層首達必得手腳傳說裝備 | 不由此推定更高層的完整獎勵週期。 |
| 星主與其他材料 | 部分回覆另列王之精魄、星核碎晶或神話碎片 | 不由未列出推定固定數量或每層必掉。 |
